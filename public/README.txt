Go4Task public logo assets

Copy ALL files in this folder directly into your project's public/ folder.

Used by the current website code:
- go4task-logo-header.png -> header on white background (dark blue text + yellow/orange mark)
- go4task-logo-hd.png -> footer on blue background (white text + yellow/orange mark)
- favicon.ico -> browser favicon
- apple-touch-icon.png -> iOS / Apple touch icon
- favicon.png, android-chrome-192x192.png, android-chrome-512x512.png -> additional icon assets

Do not put these files inside another nested folder under public/.
